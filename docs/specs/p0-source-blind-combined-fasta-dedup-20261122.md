## Causal problem and change

R042 native Ivanka emits both sequences also generated by the downstream G2P
stage. The combined FASTA has six rows but only four strand-canonical complete
molecules. The original project_stitched_counts deliberately withholds the read
counts of duplicated rows so reads are not spuriously counted twice under
multimapping. Then find_covered_contig falls back to reference-alignment
length, selecting the weaker 306-base consensus, rather than the strongly
read-supported 324-base contig.

This prospective patch deduplicates native+G2P complete DNA molecules using
the SAME existing strand-canonical molecule_key as the count projector,
strictly BEFORE remap/stitching. First occurrence remains; distinct native
sequences including minority haplotypes are preserved; empty FASTA remains
valid. No reference, truth, prior score, sample identity or genotype metadata
is used in that decision. Original read mapper and conservative count projector
are unchanged. In cases with no duplicate molecules, the old concatenate-files
path is taken and the combined input is byte-identical.
